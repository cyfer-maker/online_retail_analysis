# Online_Retail Sales Analysis
## Project Overview
End-to-end data analysis project on a real-world online retail dataset with 1M+ transactions, covering data cleaning in python and interactive dashboard in power BI.
## Tools Used
**Python (Pandas)** - Data cleaning & transfornation
**Power BI** - Interactive dashboard & Data Visualization
**GitHub** - Project hosting & portfolio
## What I Did
-Remove duplicate and unwanted columns
-Standardized month numbers to month names
-Structured columns in professional order
Built 4 - page Power BI dashboard with:
- Monthly Revenue Trend (Line Chart)
- Top 10 Countries by Revenue (Bar Chart)
- Top 10 Products by sales (Bar Chart)
- Revenue Distribution (Treemap)
